# Astryx 小范围试跑

这页让用户调整外观、通知偏好与调试模式。

- 基准：feat/desktop-ui @ f790496；继承 Claude 探针 @ 19f5cf2。
- 独立分支：feat/desktop-astryx-astra；不合入原分支，不改 Astryx 源码。
- 页面：仅设置页的三个 Switch 换成库原件，保留行、分组、字号、外观预览卡和状态所有权。通知偏好原本为临时状态，仍不宣称接通系统通知。
- 基础控件探针：Button / DropdownMenu / Dialog / Switch / Tooltip，不作为产品主页面。
- 主题：纸墨柿语义变量位于独立 paper-ink 层；Tailwind 工具类在层外。neutral 的 scoped 规则在同层会赢过普通选择器，故不能仅依靠源码顺序。
- 验收：真实页面状态切换、亮暗主题、菜单键盘/焦点回归、原界面全量测试、同环境前后截图。测试在 box1 串行执行，保留真实返回码。
- 信息层次和导航不变：外观/通知就地修改；插件与模型保持原入口；调试说明仅在高级分组。
- 进展全景原型 11-09 的五项优化已经完成；本轮不重复修改，也不借组件试跑混入其桌面同步。
- 回滚：原 feat/desktop-ui 与原探针分支均未修改；弃用本试跑分支即可。

## 已知基线问题

原 index.html 的 frame-ancestors 写在 meta 中，Chrome 会报告此指令无效。试跑保持现有安全配置；对照脚本在原版与试跑版均精确核验同一条消息，不把它算作 Astryx 新问题，也不声称控制台零报错。需由壳层任务改成响应头后移除该基线。
