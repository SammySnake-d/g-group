# 文件页：交付物有来处

预算：1 套 × 1 页面（目录、阅读、快速查看三个状态）；1440×900 与 1024×768。

本页让用户找到、阅读交付文件，并带着文件回到原对话继续讨论。

## 主张
不是文件管理后台，也不是交付数量看板。以真实内容片段替代空白主区；纸面、墨色标题与安静的间距延续原视觉语法。作者头像不是装饰，连接作品与说话的人。

- 目录可搜索文件名、作者与来源；类别单选直接缩小对象。
- 空格/眼睛快速查看，Esc 回到同一文件，不丢搜索。Dialog 的焦点、退出与动画交给 Astryx。
- 阅读时默认只留正文；相关对话按需展开，不让全时侧栏抢阅读区。
- 接着聊：返回文件所属对话；有原消息则引用并 @ 作者，没有则只填文件名与 @，不伪造消息，也不自动发送。
- 不新增介绍段、subtitle、用法说明或设计自评。正文是文件内容，不是给页面凑信息。

## 参考如何落地
- concept/load-light.png：把决策所需信息放到动作出现的地方。接着聊直接跟着文件。
- concept/ruler-frames-dark.png：少找，而不是多显示。目录用真实内容帮助识别，筛选与预览保持原位置。
- 已确认的纸墨柿界面：沿用语义色、头像、中文字体与轻边界，不另换品牌风格。

## 已接线与边界
直接读取现有 artifacts/convs/checklist/文档正文，复用已有 openConv/addQuote/setDraft。现有演示数据 5 份文件，只有 a1 有文件交付原消息；其余不声称具备原消息。没有新增后端、下载、写文件或发送权限。

## 组件边界
ClickableCard、TextInput、ToggleButtonGroup、Button、Dialog 均为 Astryx 原件；不修改组件库源码，不手写相同交互。布局与纸面表达是本页组合设计。
