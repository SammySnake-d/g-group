# g-group 前端开发优先级（2026-11-15）

用户核心故事：像 QQ 一样添加 agent 联系人、建群，在私聊/群聊里发消息并收到回复；模型接入和图片消息必须在真实后端可用。

状态口径：用 `g-group-0.1.1-preview.1-arm64.dmg` 安装版实际点按；「真实后端下已能用」只在宿主回包/持久数据可观察时记绿；网关上游鉴权/额度失败单独记为环境阻断，不把截图或本地演示当后端成功。

## Astryx 实际使用对照

已使用：`Theme`、`Switch`、`Button`、`Dialog`、`ClickableCard`、`Card`、`List/ListItem`、`HoverCard`，以及 Animate UI 的 Dialog/Popover/Dropdown primitives。手写部分集中在聊天布局、消息行、输入框状态和业务卡片；后续新增表单/弹窗/选择器优先复用 Astryx 原语，避免新增同形手写控件。

## 当前候选工作顺序

1. 先接 P0 图片粘贴与聊天附件预览入口。
2. 再接 P0 live 模型设置读写，保留后端 `confirmAffected` 影响预览和失败回退。
3. 真实上游账户恢复后重新跑私聊/群聊真实回复；在此之前保留 403/暂停原始证据。
