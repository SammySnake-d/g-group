# g-group 前端开发优先级（2026-11-15，PR #101 R2）

用户核心故事：像 QQ 一样添加 agent 联系人、建群，在私聊/群聊中发消息并收到回复；先确认文字与图片，再明确发送，聊天图片可原地查看。

本屏让用户在当前会话整理文字、引用与待发图片，删除不想发送的图片，明确发送后在原聊天查看大图。

状态依据：PR #101 R1 的 `90284d7c` 为返修起点。源码实现与替身回归、真实模型打包实点分开记录。R1 审查报告保持原样；R2 仍待独立审查，未合并。

## 本轮交互边界

- 主对象：当前会话的文字、引用和待发图片；主动作：发送。
- 未发送图片点击可放大查看，删除按钮逐张生效；发送后缩略图继续用同一原地 Dialog 查看。
- 会话切换保留草稿，错误提示跟在对应控件旁；目录失败保留当前选中值，不显示演示选项。
- 使用 Astryx `FileInput`、`AspectRatio`、`ClickableCard`、`Selector`、`Dialog`、`IconButton`；图片预览不加入场或退场动画。
- 收据、测试日志、打包 hash 和开发优先级仅在仓库证据内，不进入聊天主操作流。
