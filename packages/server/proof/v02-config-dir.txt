# 补充:--bare 下 --tools default 只展开成 Bash/Edit/Read,没有 Skill 工具;问「有哪些 skill」回答没有;
#   提示开头写 /gg-picked:gg-neutral-picked-skill 时展开成功(result 为 PICKED_MARKER);
#   让它 Read 插件目录里的 SKILL.md 绝对路径(dontAsk + --allowedTools Read)读取成功并照做(result 以 PICKED_MARKER 开头)。
# 结论:
# 1. 不带 --bare 时 CLAUDE_CONFIG_DIR 生效:只看到专属目录里的 skill,看不到 HOME 里的全局 skill(V-02 对 CC 成立)。
# 2. 带 --bare(适配器现状)时 HOME 与 CLAUDE_CONFIG_DIR 下的 skill 都不加载,全局 skill 连 /名字 也展开不了;
#    勾选的 skill 只有经 --plugin-dir 才加载,且没有 Skill 工具 → 适配器在首个提示里列出勾选 skill 与 SKILL.md 路径,Compute 需要时 Read。
# 3. 所以 AC-29 的做法:保留 --bare,专属配置目录作 CLAUDE_CONFIG_DIR(设置与会话记录不落本机 ~/.claude),勾选 skill 走 --plugin-dir,
#    MCP 走 --mcp-config + --strict-mcp-config。V-02 里 Codex(CODEX_HOME)本片没测。
