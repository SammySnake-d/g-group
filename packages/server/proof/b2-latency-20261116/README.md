## 需求和边界

- D06 §2 要求缺笔记时用同一说话模型无工具补写；D25 §12 要求每轮检查记忆/人格建议。不能直接禁用补写、反思或更改原子事务来换速度。
- 候选仅对显式声明并发安全的压缩器预启动后备；当反思成功可中止后备，没写出笔记时用后备；未声明者仍串行。撤回会对涉及会话的在途后备发送取消，已发出字节不可收回。
- 单个反思/格式变更探针在偏好场景曾耗尽上限，不足以证明保留记忆质量，因此未采用；反思后置会改变事务和下一轮可见性，未擅自实施。
- 需进一步找到不增加无谓调用、保留记忆检查的优化，并在干净环境重复前后量测。此草稿不能替代已完成修复。
